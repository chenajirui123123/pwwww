## 2.0.0-alpha3 · 初次分层

日期：2026-11-23。版本：2.0.0-alpha3（versionCode 5）。

## 改动范围

- 从 MainActivity 分离 AppState 与 WardrobeViewModel，移入 presentation。
- 引入领域层的 WardrobeRepository 接口及数据层 LocalWardrobeRepository 实现；MainActivity 通过 Factory 注入实现。
- 页面改为调用明确的 ViewModel 方法，删除所有公开的 `vm.perform { ... }` 调用，不再提交存储层代码块。
- 将单件替换的锁定、排除和搭配结构处理移入 GenerateOutfitUseCase；搭配和旅行页面通过 ViewModel 调用领域用例。
- LanguagePreferences 与动态英文模板归入 presentation；语言偏好读写及翻译资源加载由 LocalLanguageSettings 实现领域接口。
- 构建及验证脚本接入架构依赖守护检查。
