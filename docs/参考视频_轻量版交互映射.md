# 参考视频与轻量版交互映射

参考：用户提供的《【明日方舟】「促融共竞#2」活动 UI / 交互 / 动效记录》。借鉴布局、信息层级和动作规律；不复制原游戏的角色、美术、商标或界面资产。

## 本轮复看

- 82–88 秒：风格卡片从未选中到选中，莓红轮廓与功能色相区分；右侧说明随选项替换，整体框架不移动。
- 90 秒附近：白色小卡片、深色标题、紧凑英文副标题和大面积主操作区。
- 148 秒附近：说明卡片横向切换，前后卡片短暂并存，用方向表达层级。
- 170–176 秒：选项切换保留共同框架，鲜明主题色只突出当前选择。

## 落地

| 参考规律 | 衣序轻量版 |
| --- | --- |
| 稳定框架，局部替换 | 搭配板按类别保持格位；未改变的锁定单品不重播换件动画 |
| 卡片轮廓表达选择 | 锁定单品用莓红边框和锁形标记，支持直接点击切换 |
| 短促的横向运动 | 换件进入 280 ms、延迟 35 ms；退出 170 ms，带淡入淡出 |
| 前进和返回有方向 | 页面按导航实例顺序滑入，返回采用相反方向 |
| 信息层级强于装饰 | 大号中文主标题、紧凑英文模块标签、醒目数字；首页优先搜索与衣物 |
| 操作有即时反馈 | 按钮和卡片按压缩至 0.965 / 0.97，110 ms 恢复；选中边框 160 ms 变化 |

Android 系统动画时长缩放仍由 Compose 动画机制遵循；不加入无限循环和阻塞操作的开场动画。字体、矢量衣物和已有原创图层保持离线可用。
