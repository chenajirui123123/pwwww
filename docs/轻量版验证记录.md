## 第三轮：分享与批量录入

- 从系统分享 Intent 接收图片，先确认当前空间，再进入新草稿；原来的未保存草稿仍可返回继续。完整 UI 旅程已覆盖该行为。
- 360 dp 宽（1080×2160、density 480）、1.3 倍字体下核心旅程通过。检查后将“换一套 / 收藏”固定到底部，提示条上移避开操作栏。
- 批量照片草稿在 Activity 重建后仍保留；每批最多 20 件，数据库整批事务保存。通过系统文档选择结果夹具验证双图导入、保存；系统选择器本身另行人工检查。
- 新增失败批量回滚与照片清理保护测试；累计 20 项安卓测试通过（19 项数据层 + 1 项完整旅程）。20 项 JVM 规则测试通过。
- 统计与洗护文字修订为主动记录口径，不将未登记推断为未穿或待洗。
- 分享实现参考 Android 官方文档 https://developer.android.com/develop/ui/compose/sharing/receive ，不申请全相册权限，不处理外部任意文件路径。
