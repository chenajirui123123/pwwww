## 自动化覆盖

JVM 测试检查实际穿着的日期和衣物选择校验、无效日期与未来日期、撤销及计划不计数、闲置天数、衣物价格与款式校验、备份加密往返、错误口令和密文篡改。

Android 数据层测试检查：账号读写隔离；计划重复确认与快照独立；撤销重算且不回滚洗护；归档与恢复保留两类历史；真实洗护变化才记日志；位置调整独立；日期修正；重新打开数据库后会话与内容保留；加密备份恢复和错误口令拒绝；示例账号名不可注册绕过私人密码；图片采样、账号私有路径、照片备份恢复、无效图片及超过 5 MB 的文件拒绝。

完整 UI 流程包含：进入示例衣橱 → 录入连衣裙 → 搜索与查看 → Activity 重建后保留当前详情页 → 改为待洗 → 创建手动搭配 → 安排计划 → 确认实际穿着 → 洗护列表 → 统计 → 个人中心 → 穿着历史。自动化中的表单保存使用 Compose 语义点击回调；另外使用 ADB 系统触控验证了衣物文本录入与保存、“确认实际穿着”和“保存实际穿着”的真实点击、落库与页面返回。

## 复现命令

在工程根目录，先选择一台专用测试设备；完整 UI 流程会增加示例衣橱测试记录。

```bash
export JAVA_HOME='/Applications/Android Studio.app/Contents/jbr/Contents/Home'
./gradlew --offline :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
ANDROID_SERIAL=emulator-5556 ./gradlew --offline :app:connectedDebugAndroidTest
```

`emulator-5556` 是本次专用设备序列号，其他电脑上先用 `adb devices` 确认并替换。首次构建未缓存依赖时去掉 `--offline`。本次最终设备验证使用 `am instrument`，保留截图与应用状态，完整原始输出见上述设备测试日志；输出尾部 `OK (11 tests)` 表示 10 个数据测试加 1 个界面测试通过。
