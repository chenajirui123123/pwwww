# 衣序的视觉与交互设计

## 参考与转化

参考资料：用户提供的《【明日方舟】「促融共竞#2」活动 UI / 交互 / 动效记录》视频，时长约 8 分 32 秒。检查了不同页面截图及约 148 秒处的连续转场帧。

提取的设计特征包括冷灰白底色、大面积炭黑、少量高饱和青绿和莓红、斜切角面板、粗标题、细线图标、编号式辅助标签，以及短距离滑动叠加透明度变化。应用中重新绘制品牌、衣物和操作图标；游戏角色、游戏标志和截图未作为界面资产使用。

“衣序”的页面围绕五项日常任务：找衣服、做搭配、安排日期、处理洗护、观察使用情况。按钮文字保持中文，英文只作为辅助编号和装饰标签。

## 配色与组件

| 用途 | 颜色 |
| --- | --- |
| 正文、底栏、深色面板 | `#20272A` |
| 页面底色 | `#F1F2EF` |
| 次要文字 | `#6A777B` |
| 选中态、重点指示 | `#28C4BD` |
| 主要操作、重点提示 | `#CE174C` |
| 少量点缀 | `#DCEB97` |

主面板右上、左下切角为 14 dp，小面板为 8 dp。操作按钮至少 50 dp 高，交互标签至少 48 dp 高。按钮使用 100 ms 的 0.98 倍按压缩放。页面进入为 220 ms 淡入与 260 ms 横向移动（宽度的 1/12）；退出为 120 ms 淡出与 180 ms 反向移动（宽度的 1/20）。底栏切换带轻触反馈。

页面里的文字、输入框、日历、统计和按钮都是可操作的 Compose 组件。首页插画作为底层图片，文字由界面独立绘制，保证字号和清晰度。

## 男装、女装及中性款式

不按性别限制分类或衣物组合。默认款式插画覆盖：

| 分类 | 款式 |
| --- | --- |
| 上装 | 衬衫、T 恤、针织、卫衣 |
| 下装 | 长裤、短裤、半裙 |
| 连衣裙 | 连衣裙 |
| 外套 | 夹克、风衣、西装 |
| 鞋履 | 运动鞋、低跟鞋、短靴 |
| 包袋 | 手提包、双肩包 |
| 配饰 | 围巾、帽子 |

共 18 种款式。首屏插画将衬衫、长裤、夹克、连衣裙、半裙、运动鞋、低跟鞋及包袋放在同一展陈空间。示例衣橱包含 14 件单品和 5 套搭配，兼顾不同风格。用户可以上传自己的衣物照片替代插画。

衣物轮廓使用 Canvas 路径绘制，颜色跟随资料中的颜色选项；导航图标使用一致的 24 单位坐标与 1.7 单位线宽。图标包括衣架、搭配、日历、水滴、统计、用户、添加、搜索、返回、编辑、筛选、归档、时钟等。西装采用翻领、双侧口袋和长袖轮廓，夹克使用拉链及收口，围巾具有绕颈环、垂片和流苏，避免以同一个轮廓替代不同款式。代码入口为 `ui/Design.kt`；桌面图标为 `res/drawable/ic_launcher.xml`。

使用 **内置 image_gen 工具**完成初次生成和男女装兼顾版本的编辑，没有使用 CLI 或第三方图库。最终资产已经复制进工程，运行时不依赖生成工具或外部路径。

- 设计归档：[最终版](design/wardrobe_hero_inclusive.png)、[初始版](design/wardrobe_hero_initial.png)
- 格式：1536 × 1024 PNG，不透明背景。

初次生成提示词：

A sophisticated isometric architectural fashion installation: a sculptural white modular clothing rack, beautifully modeled ivory overshirt, slate blue tailored trousers, a pale mint jacket, white minimal sneakers and a small structured charcoal bag, on layered angular white exhibition platforms. High end 3D editorial rendering with pale cool gray background, matte ceramic white architecture, charcoal trim, turquoise #30C6C2 and small saturated raspberry #D3124E accents, tiny lime details. Strong crisp diagonal shapes, precise soft ambient shadows, restrained technical line details, elegant modern functionalism. Concentrate the installation in the right two thirds; left third should be mostly quiet gray negative space for UI text to be layered in code.
