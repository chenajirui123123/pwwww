# 衣序 1.1：视觉与交互升级

修改前的完整工作版本已提交 Git：`340f56a`。本轮重点是用户指出的等宽、疏松英文标签，以及全应用的视觉一致性。

## 从视频中提取的设计方法

参考用户提供的《【明日方舟】「促融共竞#2」活动 UI / 交互 / 动效记录》，重新检查了前后段画面、90 秒处风格卡片，以及约 148 秒处连续转场帧。借鉴的是信息组织、字体层级、几何构成与动作方向，应用中的服饰插画和图标均为独立制作。

| 视频中的设计特征 | 衣序中的实现 |
| --- | --- |
| 粗标题与紧凑英文形成大小对比 | 中文主标题 23–31 sp；英文采用 Barlow Condensed SemiBold/Bold，13 sp、0.25 sp 字距；中文辅助信息使用系统中文字体，11 sp、不扩张字距 |
| 大编号与任务进度数字 | 章节、衣物编号、搭配编号、统计值使用 ExtraBold Italic 数字；`0 PLANS` 拆成重点数字和辅助名称 |
| 黑白信息条、灰白底、青绿及莓红 | 深色统计面板；深色选中标签及青绿识别条；莓红主操作按钮；深青绿文字用于白底上的清晰显示 |
| 卡片边框、几何边角、分区线 | 统一非对称切角、细边框、网格、定位角标及三条斜线装饰；底部导航也采用相同几何规则 |
| 展陈式空间层次 | 衣橱展台、搭配板、洗护器物三个独立图层；文字与控件由 Compose 叠加，支持字体缩放 |
| 横向推进与透明度过渡 | 前进向左推进，返回反向；底栏切换根据目标位置选择方向；颜色过渡及短按反馈 |

## 字体与组件

- 字体源：[Google Fonts / Barlow Condensed](https://github.com/google/fonts/tree/main/ofl/barlowcondensed)，[随工程保留的 OFL 许可证](licenses/BarlowCondensed-OFL.txt)。字体文件在 `app/src/main/res/font/`，不依赖网络下载。
- `Micro` 已从等宽字体改为紧凑比例字体，不再用 1 sp 宽字距。
- `ModuleHeading`、`CodeLabel`、`Numeral`、`AtelierNavigation`、`AtelierTextField` 集中在 `ui/VisualSystem.kt`。
- 页面背景 `#EEF0ED`，正文 `#20272A`，辅助文字 `#59676B`；亮青绿 `#28C4BD` 用于色块与深色背景，深青绿 `#087B73` 用于浅底文字；主操作为 `#CE174C`。
- 主面板右上切角 12 dp、左下 4 dp；小面板右上 7 dp、左下 2 dp。按钮、可点击标签和图标保持至少 48 dp 操作区域。
- 标签保留选中语义，导航保留 `Role.Tab` 和选择组语义；图标按钮保留中文无障碍名称。衣物状态除了颜色也有中文文字。
- 统一登录、注册、档案编辑、日期、昵称、密码和备份输入框。空状态、个人资料、历史列表、详情、应用图标均使用同一套边角和颜色。
- 衣物插画继续支持 18 种男装、女装和中性款式；底图增加轻网格，搭配预览改为主单品与辅助单品分区。
- 统计环和条形图改为原生绘制，数据长度仍表示真实比例，四角、刻度和分隔线为独立装饰。

## 动效参数

页面进入：35 ms 延迟、230 ms 淡入、300 ms 横移（宽度 1/9）；离开：130 ms 淡出、220 ms 反向横移（宽度 1/14），使用 FastOutSlowIn。底部导航颜色过渡 180 ms；筛选标签颜色过渡 160 ms；按钮按下 110 ms 缩放至 0.965；使用率环 650 ms 展开。使用 Compose 动画体系，遵循系统动画时长设置，没有常驻循环动画。

## 验证与数据

真实截图见 [screenshots-v1.1](screenshots-v1.1/)。截图来自模拟器中的独立预览包，演示衣物及测试记录不代表用户真实数据。

为了使界面流程测试不修改原应用数据，增加了仅供开发使用的 `-PisolatedPreview` 构建参数；它将应用安装为 `com.wardrobe.atelier.preview`。普通 Android Studio Run 和普通构建仍使用原包名 `com.wardrobe.atelier`，数据库及数据格式没有更改。

本轮检查了 1080 × 2400、420 dpi 默认字号，以及 1080 × 2160、480 dpi（360 dp 宽）、115% 字号。日历标题分层、主标题与操作按钮、筛选横向滚动、表单固定保存栏和导航均可正常显示和操作；短屏内容通过正常滚动访问。
