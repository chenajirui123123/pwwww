# 中英文切换 · 2.0.0-alpha2

日期：2026-11-17。

## 使用方式

欢迎页与“我的”页面均可选择“简体中文 / English”。界面即时更新，选择保存在本机，所有本机账号共用这一显示偏好。首次使用默认中文。

英文覆盖衣橱、搭配、旅行胶囊、录入、个人设置、备份、日历、洗护、统计与常用错误提示。用户录入的名称、位置、品牌、备注与历史数据不改写；既有示例衣物名称也保留原文。系统文件选择器等 Android 系统界面的语言由系统设置决定。

## 实现

- `ui/Language.kt` 管理本机语言偏好、显示转换和动态数量模板。
- `assets/english.json` 集中保存英文界面文案；新增 UI 文案时同步维护此文件。
- 翻译仅发生在显示边界，不翻译数据库类别值、筛选条件或状态枚举，避免旧数据失效。
- 衣物与搭配的用户名称、备注等直接显示原文。语言切换不重新建立衣橱，也不新增穿着或洗护记录。
- 英文搜索补充匹配翻译后的颜色、类别、款式和季节，同时保留原始名称、位置搜索。
- 版本号增加到 4 / 2.0.0-alpha2，包名仍为 `com.wardrobe.atelier.light`。
